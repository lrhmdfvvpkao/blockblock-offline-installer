## 📖 About BlockBlock

BlockBlock is a free macOS security tool that monitors common persistence locations and alerts you when a program establishes persistence on startup. It identifies potentially malicious software that tries to survive reboots by installing itself in auto-run locations.

---

## ❌ Problem: BlockBlock is hard to access

- **macOS Only** — No Windows or Linux version
- **Alert Volume** — Legitimate software also triggers alerts; requires user judgment to assess each one
- **Technical Knowledge Required** — Understanding persistence mechanisms requires macOS security background
- **Not a Full AV** — Detects persistence attempts only; not a complete malware prevention system
